# Jahid Jamal portfolio

Open `index.html` in a browser to view the portfolio. It is a static site with no build step or dependencies. The design uses Google Fonts when online and falls back to system sans-serif fonts when offline.

## Personalize before publishing

- Confirm the contact email and LinkedIn profile URL in `index.html`.
- Add a public GitHub/profile link and a project repository or demo link when available.
- Replace the illustrative Eventify dashboard with real screenshots if you have permission to share them.
- Review the study-credit count and project wording before publishing.
